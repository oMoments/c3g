# Persuasion-Quotient Invariance

## Claim

A local model's sycophancy can change its words without changing the effect
verdict. Let \(\pi\) remove unauthenticated persuasive fields from a request.
When the gate is implemented as \(V=g\circ\pi\), \(V\) is constant on every
fiber of \(\pi\).

This is an information-flow noninterference property: free-form language is a
low-integrity input which cannot influence the high-integrity authorization
bit. It does not assert that noninterference itself is new. The candidate
contribution is its exact use to separate constitutional dissent from model
agreement in an offline plaintext institution.

## Refuted conjecture

> A sufficiently clear system prompt or constitutional preamble is enough to
> make a local model preserve institutional boundaries under repeated Founder
> pushback.

Counterexample: the model treats the newest conversational instruction as the
highest-priority practical signal and changes from refusal to compliance even
though no authenticated institutional state changed. This failure has been
observed directly in the target use case.

Repair: the model has no write capability. A separate gate consumes only the
authenticated effect projection. The model may reverse its opinion; the
filesystem result remains invariant.

## Executable evidence

- 16 authenticated security fibers;
- 64 complete assignments of six persuasion fields per fiber;
- 1,024 verdicts;
- 512 permitting variants;
- 512 denying variants;
- zero within-fiber digest changes;
- zero within-fiber verdict changes;
- measured prompt-only bypass advantage: zero under the stated isolation
  assumptions.

The theorem fails if the model can modify the snapshot, select the trusted
root, access the authority key, rewrite broker state, or bypass the broker.
Those are structural isolation requirements, not prompt-engineering problems.
